jab bhi count or substring or subarrays ki baat ho

pattern 
start and end 

two variables point at start  --- i= start and j=start

now start loop from start till end -- for(j;j<=end;j++)

do what question ask -- eg increase count of character’s -- freq[ch[j]]++;

now check for windowsize, fixed or variable length -- if(j-i+1>windowsize){}
    then decrease the freq of char at ith index 
    and move i++ i.e slide the window
